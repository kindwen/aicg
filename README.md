# 汽车 AIGC 创作工作台（AUTO PROMPT BOARD）

面向**懂车帝 AI 汽车图文创作**的一站式工作台：内置懂车帝全量车系数据 + 多视角参考图 + 本地 Prompt 生成器 + 可选的 AI 增强（用户自配 Key）。

> 单文件 HTML 即可离线使用，零依赖；AI 增强为可选能力，由用户自配置 Key，源码不含任何真实密钥。

## ✨ 核心特性

- **懂车帝全量车系库**：4534 款车系 / 645 个品牌，100% 真实封面图，离线可用
- **多视角参考图**：135 款热门车系预抓取「外观 3 + 内饰 2」多视角图，一键复制
- **榜单真实化**：热门榜 / 销量榜走懂车帝真实接口，车型库品牌 A-Z 索引（唯一归位、可展开收起）
- **本地 Prompt 生成器**：内容方向 + 信息点 + 视觉设置 + 车型事实 → 自动生成标题与 Prompt
- **AI 增强（可选）**：OpenAI / DeepSeek / 通义千问 / 智谱 GLM / 豆包 等，失败自动回退本地模板
- **数据本地化**：Key 存浏览器 localStorage，经本地服务安全转发，不落盘、不上传第三方

## 🚀 快速开始

### 基础使用（离线，零配置）

双击打开 `auto-prompt-board.html` 即可使用全部基础功能（数据已内联）。

### 启用 AI 增强（可选）

1. 启动本地数据服务（同时承担 AI 转发代理，规避浏览器跨域限制）：

   ```bash
   python dongchedi_server.py
   ```

2. 打开网页 → 设置页 → 选择 AI 服务商 → 粘贴你自己的 API Key → 测试连接 → 开启 AI。

> 为什么需要本地服务？DeepSeek / 通义 / 智谱 / 豆包等国内大模型 API 不开放浏览器跨域（CORS），前端无法直连。本地服务作为同源代理转发请求，Key 仅在单次请求中使用，不落盘、不缓存。

| `dcd_photos.js` | 多视角图数据（内联版） |
| `fetch_all.py` | 懂车帝数据抓取脚本 |
| `懂车帝车型库抓取实现方法论.md` | 数据抓取方法论（2026-08 实测验证） |
| `第二阶段技术实施方案.md` | 二期迭代技术方案 |

## 🔧 数据更新

全量数据为抓取时点快照，如需更新可重跑：

```bash
python fetch_all.py        # 抓取全量车系 + 参考图
# 之后手动将新数据内联回 auto-prompt-board.html（参考 gen_inline.py / patch_html.py 流程）
```

## ⚠️ 隐私与安全

- 源码**不含任何真实 API Key**，AI Key 由用户自行配置，存于用户浏览器 localStorage。
- 本地服务 `/api/ai` 代理仅转发请求，不记录、不缓存 Key。
- 若你曾在对话或其他渠道泄露过 Key，请到对应服务商后台重置。
